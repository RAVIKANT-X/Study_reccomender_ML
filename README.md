
# 🎓 Study Strategy Recommender System (Machine Learning)

## 📌 Overview
This project is a Machine Learning-based system that recommends personalized study strategies for students based on their performance data.

It analyzes features such as marks, attendance, study hours, assignment scores, and sleep patterns to suggest actions like:
- Revise Basics
- Practice More
- Focus on Weak Topics
- Do Advanced Questions
- Maintain Performance

---

## 🎯 Problem Statement
Students often struggle to understand how to improve their academic performance.  
This project aims to provide **data-driven, personalized recommendations** using machine learning.

---

## ⚙️ Features
- Multiple ML models implemented:
  - Decision Tree
  - Random Forest
  - Logistic Regression
- Model comparison using:
  - Accuracy
  - F1 Score
- Realistic synthetic dataset (500 rows)
- Interactive web app using Streamlit

---

## 🧠 Machine Learning Approach
- Problem Type: **Classification**
- Input Features:
  - Marks
  - Attendance
  - Study Hours
  - Assignment Score
  - Sleep Hours
- Output:
  - Recommended Study Strategy

---

## 📊 Model Evaluation
The models are evaluated using:
- Accuracy
- F1 Score (important for imbalanced data)

Random Forest performed best due to its ability to handle non-linear relationships.
